# Décisions

Une ligne par arbitrage : date, choix, pourquoi, alternative écartée.

- 2026-11-12 — Nom : blockquilt (des blocs cousus en un seul texte, libre sur npm et GitHub). Écartés : blockpen, blockquill, blockstitch, blocmark.
- 2026-11-12 — Extraction telle quelle de l'éditeur de rubrique d'easyHomeGuide (commit `07ec88a`) ; easyHomeGuide garde sa copie. Écarté : le hub stackfast (plus tard, peut-être).
- 2026-11-12 — Docker : `node:22-alpine` pour la démo, `node:22-slim` + Chromium (paquet Debian) pour la validation. Aucune dépendance npm : serveur avec `node:http`, multipart lu par `Request.formData()`, CDP par le `WebSocket` intégré à Node 22. Écartés : Puppeteer/Playwright (dépendances lourdes), une démo sans serveur (enregistrer et photo non testables).
- 2026-11-12 — Polices Plus Jakarta Sans et Newsreader livrées avec leur licence SIL OFL 1.1 (`fonts/OFL-*.txt`), le dépôt étant public.
- 2026-11-12 — Licence MIT pour le code (réutilisation libre, le but est l'intégration dans d'autres projets). Les polices gardent la SIL OFL 1.1.
- 2026-11-12 — Visualisation : rendu invité dans le noyau (`Blocks.toHtml`, fonction pure) avec les teintes de `Blocks.TYPES`, utilisé par le serveur de démo et par l'éditeur quand `data-preview` est absent. easyHomeGuide garde son rendu PHP (`markdown.php`, variables du homebook). Écartés : une dépendance Markdown npm (le projet n'en a aucune), recopier le rendu PHP en JS (deux lectures du Markdown au lieu d'une).
- 2026-11-12 — Phase 1 : retrait de `app.js`, `reference/`, `docs/`, de la fausse IA locale (expressions régulières) et du type « audio » ; les feuilles `<dialog>` sont gérées par `blockquilt.js`. Préfixe `bq` à la place de `ehg`. Écarté : garder `app.js` pour 25 lignes utiles.
- 2026-11-12 — Phase 2 : registre `Blocks.register(type, def)` ; un bloc est lu par le premier type (ordre d'enregistrement) dont l'écriture redonne le même texte, sinon `raw`. Noyau (`blockquilt.js`, utilisable sous Node) et écran (`blockquilt-editor.js`, ajoute `edit`/`read`) séparés. Un type sans carte d'édition propre est édité comme texte source. Écarté : un `switch` par fonction (sept endroits à toucher par type).
- 2026-11-12 — Phase 3 : format pivot unique (FORMAT.md) : frontmatter `clé: valeur` à plat, encadrés `> [!type]` (info, tip, success, warning, danger) en minuscules, `##`/`###`, `---`, code clôturé. Aucun code de lecture de l'ancien format (`## 🏡 Titre`, `> 💡`, `:::sensible`) : il tombe en H2, citation ou bloc source, sans perte. Écarté : `[!TIP]` en majuscules (reste un bloc source, signalé par `lint`) pour garder une seule écriture.
- 2026-11-12 — Rendu publié : `<article class="bq-content">`, `<h1>` depuis le frontmatter (option `title: false`), classes `bq-*` et feuille `blockquilt-content.css` écrite à la main (couleurs en variables CSS). Un bloc source est rendu en `<pre class="bq-raw">`, texte échappé, jamais interprété. Écarté : interpréter les tableaux ou le HTML d'un bloc source.
- 2026-11-12 — Photo : `![légende](media/<id>)` ou `https://…` (modèle `src`). Légende = `alt` + `<figcaption>`. Code en ligne `` `x` `` reconnu dans le texte. Groupe `structure` (ligne, code) ajouté à `text` et `media` pour le menu d'ajout.
- 2026-11-12 — Phase 4 : `Blockquilt.mount(element, options)` fabrique tout l'écran (en-tête, cartes, feuilles) ; icônes SVG en ligne (tracés Lucide) et aucun attribut `id` : plusieurs éditeurs cohabitent dans une page. Tous les écouteurs passent par un `AbortController` : `destroy()` les retire d'un coup. Échanges : `fields` (ex. jeton CSRF) + `text` (enregistrer, aperçu) ou `photo` (envoi, réponse `{ id }` ou `{ src }`). Écarté : garder le HTML de l'éditeur dans la page hôte (85 lignes à recopier).
- 2026-11-12 — Carte de bloc : badge de type (liste de conversion) à gauche, poignée et menu « ⋯ » à droite ; monter, descendre, dupliquer et supprimer passent dans le menu. Boutons « Insérer » et « Fusionner » avec une cible de 44 px mais une pastille de 28 px. Écarté : rail latéral et corbeille en bas de carte (vide sous les titres).
- 2026-11-12 — Phase 5 : historique de 50 instantanés (texte complet + place du bloc actif), pris avant et après chaque action de structure et après 1 s sans frappe ; pendant une frappe, Ctrl+Z reste au navigateur. Écarté : 10 instantanés (trop court dès qu'on réorganise), un historique par opération (plus de code, plus de cas).
- 2026-11-12 — Barre de mise en forme fixe et centrée (bas de l'écran visible au téléphone, sous l'en-tête à l'ordinateur), ouverte par sélection, double clic, appui long ou clic droit, fermée à la perte du focus ; elle ne garde que le style et « scinder ». Les actions sur le bloc vont dans le menu « ⋯ ». Écarté : une barre qui suit la sélection, un menu unique chargé.
- 2026-11-12 — Glisser-déposer : l'ordre ne change qu'au lâcher ; trait bleu de 3 px, copie qui suit le doigt, Échap annule. Plein écran : un `<dialog>` modal de 100dvw × 100dvh (éditeur entier déplacé dedans, ou bloc seul), plus `requestFullscreen()` quand il est permis. Copier / coller : Markdown du bloc dans le presse-papiers (copie interne en secours), collage découpé par `Blocks.parse`.
